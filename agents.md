# Project Instructions

## Rule changes

- Changes can be made to AGENTS.md when request by me.

## Allowed change scope

- For the time being, only create, edit, move, or delete files inside the root-level `css/`, `js/`, and `fonts/` directories.
- Files outside `css/`, `js/`, and `fonts/` may be inspected when necessary, but must not be modified.
- Do not run formatting, generation, build, or other commands that write files outside `css/`, `js/`, or `fonts/`.
- If a requested task requires changes outside these directories, stop and ask for explicit permission before making those changes.

## Styling conventions

- Always write responsive styles mobile-first: use the narrow-screen layout as the default and add enhancements with increasing `min-width` or `width >` breakpoints.
- In SCSS files, always use SCSS single-line comments (`//`) instead of CSS block comments (`/* ... */`).
